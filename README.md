# Safe Scripts WP Template

Набор готовых сниппетов и шаблонов для типовых доработок сайтов на WordPress. Я собираю сюда всё, что использую в ежедневной работе: от CSS-правок до готовых PHP-фрагментов. Это экономит время — не нужно каждый раз писать одно и то же.

## Что внутри
- **CSS-сниппеты:** исправление отступов, выравнивание блоков, скрытие лишних элементов, быстрые правки адаптива.
- **PHP-фрагменты:** типовые хуки и фильтры для WordPress (например, отключение комментариев или добавление мета-тегов).
- **JS-скрипты:** простые скрипты для фронтенда без тяжелых зависимостей.

## Зачем это заказчику
Если вы видите в этом репозитории решение своей проблемы — значит, я уже делал такую задачу и знаю, как её решить стабильно и без конфликтов с темой.

## Как использовать
Просто скопируйте нужный фрагмент кода в соответствующую часть вашего проекта (functions.php, style.css или через плагин Code Snippets).
