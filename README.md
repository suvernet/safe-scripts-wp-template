# Safe Scripts WP Template

Коллекция типовых сниппетов и шаблонов для доработок сайтов на WordPress. Я собираю сюда всё, что использую в ежедневной работе: от CSS‑правок до готовых PHP‑фрагментов. Это экономит время — не нужно каждый раз писать одно и то же.

## Философия проекта

- **Стабильность:** каждый сниппет проверен на нескольких проектах.
- **Чистота:** минимум зависимостей, код понятен даже через полгода.
- **Скорость:** типовые решения позволяют брать задачу и сразу делать результат.

## Что внутри

- **php/** — PHP‑фрагменты для интеграции в WordPress (отключение комментариев, подключение скриптов и т.д.).
- **css/** — готовые CSS‑стили для типовых правок (отступы, выравнивание, скрытие элементов).
- **js/** — простые JavaScript‑скрипты для фронтенда без тяжелых зависимостей.

## Как использовать

Просто скопируйте нужный фрагмент кода в соответствующую часть вашего проекта:
- PHP‑сниппеты — в `functions.php` вашей темы или в плагин Code Snippets.
- CSS — в файл стилей вашей темы или через настройки «Дополнительные стили» в кастомайзере.
- JS — в ваш JS‑файл темы или через плагин для вставки скриптов.

## Примеры сниппетов

- `php/disable-comments.php` — отключает комментарии на всём сайте.
- `php/enqueue-custom-scripts.php` — правильный способ подключения своих скриптов и стилей.
- `css/quick-fixes.css` — быстрые CSS‑правки для частых проблем.
- `js/frontend-utils.js` — простые утилиты для фронтенда.
